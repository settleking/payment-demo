# Security

This repository is sample code: it shows how a merchant site integrates SettleKing and is not a
production system. Its simplifications are listed in the README ("Notes for production").

**Reporting a vulnerability.** If you find a security problem in this sample, or in SettleKing
itself, please do not open a public issue. Email **security@settleking.com** with what you found and
how to reproduce it. We will confirm receipt and keep you informed.

Never put real API secrets, webhook secrets or card data in an issue or pull request.
